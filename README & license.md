# RawPilot
RawPilot is a free software for photograph to help organize picture in folder with a build-in raw-to-jprg conversion, possibility to store documents like contracts, choose if its a events or a shooting, possibility to put an event poster, buillt-in checklist and even more for and much more optimized workflow
